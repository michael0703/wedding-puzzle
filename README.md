# 婚禮網頁解謎：阿豪の小天地

仿 2011 年部落格風格的解謎小遊戲。賓客用手機掃 QR code 遊玩，破關後可以登記抽獎。

## 謎題流程

1. **相簿「我們」**：讀完 5 篇網誌，拼出密碼（小木屋鬆餅）
2. **照片排序**：把相簿裡的 5 張照片拖到格子裡排好 → 照片各對應一篇文章，照文章的**發表時間**排
   （首頁文章故意不照時間排，要玩家自己發現）
3. **謎題 3**（待設計）：排好照片後才出現的文章 → 解開置頂文章〈給未來的妳〉
4. **破關**：感謝影片 → 輸入名字 → 拿到抽獎序號（請賓客截圖）→ 自動登記到 Google 試算表

## 要編輯的檔案

| 檔案 | 內容 |
|---|---|
| `content/posts/*.md` | **文章**，一篇一個檔案 |
| `content/posts.json` | 首頁文章的**顯示順序**（置頂文章永遠在最上面） |
| `content/settings.js` | 部落格標題、密碼與提示、相簿、留言板、關於我、結局、影片、抽獎網址 |
| `photos/` | 照片放這裡 |

### 文章格式

```
---
標題: 期末考終於結束了！！
日期: 2011/06/20 22:15
心情: 😆
照片: exam.jpg
---
文章內容寫在這裡。

空一行是新段落，直接換行就是換行。**這樣**是粗體。
```

開頭 `---` 之間的欄位：

| 欄位 | 說明 |
|---|---|
| `標題`、`日期`、`心情` | 顯示在文章上 |
| `照片` | 有寫的文章，它的照片就會出現在排序謎題裡。正確順序**自動依照這些文章的日期**計算。填檔名（放在 `photos/`），還沒有照片時可以填「🎂 生日蛋糕」這種表情符號加文字當佔位 |
| `置頂: 是` | 置頂文章 |
| `上鎖: final` | 要解開關卡 `final` 才能讀（關卡在 `settings.js` 的 `locks`） |
| `出現條件: order` | 解開關卡 `order` 之後才會出現在首頁 |

新增文章：在 `content/posts/` 新增一個 `.md` 檔，再把檔名加進 `content/posts.json`。

### 改密碼和提示

在 `content/settings.js` 的 `locks`：

- `answers`：正確答案。比對時會忽略空白、標點、全形半形
- `nearMisses`：接近但不對的答案，給玩家專屬提示
- `hints`：前兩個是提示，最後一個是答案

## 本機預覽

**雙擊 `start.bat`**（需要電腦有 Python），會自動開啟 http://localhost:8000/ 。關掉黑色視窗就停止。

> 直接雙擊 `index.html` 不行：瀏覽器不允許網頁讀取電腦裡的文章檔案。

網址加上 `?reset` 可以清除進度（例如 `http://localhost:8000/?reset`），「關於我」頁最下面也有重新開始的按鈕。

## 感謝影片

1. 影片上傳到 YouTube，**瀏覽權限**選「不公開」
2. 複製影片網址最後那串 ID（例如 `https://youtu.be/AbCdEf12345` 的 `AbCdEf12345`）
3. 填進 `content/settings.js` 的 `ending.youtubeId`

## 抽獎登記設定（Google 試算表）

1. 開一個新的 Google 試算表，取名例如「婚禮破關名單」
2. 上方選單 **擴充功能 → Apps Script**
3. 把 `setup/google-apps-script.gs` 的內容整個貼上（取代原本的內容），按儲存
4. 右上角 **部署 → 新增部署作業**
   - 類型選「**網頁應用程式**」
   - 執行身分：**我**
   - 誰可以存取：**所有人**
5. 按部署，第一次會要求授權（會出現「Google 尚未驗證這個應用程式」，按「進階 → 前往」即可，這是你自己寫的程式）
6. 複製「網頁應用程式網址」（`https://script.google.com/macros/s/.../exec`），填進 `content/settings.js` 的 `sheetUrl`

賓客破關登記後，試算表會自動多一個「破關名單」分頁，欄位是：登記時間、名字、序號、解謎時間、提示次數。

**抽獎**：在試算表任一格輸入下面的公式，每次修改任何儲存格都會重抽一次：

```
=INDEX(破關名單!B2:C, RANDBETWEEN(1, COUNTA(破關名單!C2:C)), 0)
```

> 修改 Apps Script 之後要重新部署：**部署 → 管理部署作業 → 編輯 → 版本選「新版本」**，網址不會變。
