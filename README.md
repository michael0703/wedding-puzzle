# 婚禮網頁解謎：阿豪の小天地

仿 2011 年部落格風格的解謎小遊戲，賓客用手機掃 QR code 遊玩，約 10–15 分鐘。

## 檔案

| 檔案 | 用途 |
|---|---|
| `data.js` | **所有故事內容**：文章、相簿、留言、密碼、提示、結局。換素材只改這裡 |
| `app.js` | 遊戲邏輯（換頁、密碼判定、提示、進度保存） |
| `style.css` | 外觀 |
| `index.html` | 入口 |

## 謎題流程

1. **相簿「秘密」**：密碼是相遇日期 → 線索在文章〈今天遇到一個很特別的人〉的發表日期
2. **文章〈不能說的秘密〉**：密碼是「她最常叫我的兩個字」→ 線索是留言板上忘記切注音的亂碼
3. **置頂〈給未來的妳〉**：解開 1 後相簿照片有粉紅色的字，解開 2 會知道要照日期排 → 拼出密碼

## 換成真實素材

- 照片放在 `photos/` 資料夾，在 `data.js` 對應照片填 `src: 'photos/檔名.jpg'`
- 照片說明裡用 `{字}` 標記粉紅色關鍵字
- 改密碼時，要一起改：`locks` 裡的 `answers`、`hints`，以及藏線索的文章或留言內容
- `nearMisses` 是「接近但不對」的答案，可以給玩家專屬提示

## 本機預覽

直接雙擊 `index.html` 就能玩。
網址加上 `?reset` 可以清除進度（例如 `index.html?reset`），「關於我」頁最下面也有重新開始的按鈕。

## 部署

純靜態網站，不需要 build，把整個資料夾部署到 Vercel 或 GitHub Pages 都可以。
